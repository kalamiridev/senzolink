# SenzoLink Open Components

Public integrations and supporting components previously maintained in this repository have moved to **Kalamiri Labs**.

## FusionSolar MQTT

The FusionSolar MQTT bridge is now maintained at:

https://github.com/kalamiridev/kalamiri-labs/tree/main/integrations/fusionsolar-mqtt

The service reads Huawei FusionSolar plant data, publishes it to MQTT and optionally provides Home Assistant MQTT Discovery.
